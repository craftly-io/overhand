The coding agents you already use, kept working while you're away.

  • On your computer {{name}} runs your agents across all your projects and brings back only what takes a person.
  • Nothing merges on its own Every change comes back as a pull request with the checks it ran. Merging stays yours unless you choose otherwise for a project.

Eight words.

  • Project A repo you've given {{name}}, or a few repos from one owner kept together.
  • Agent A coding tool you already use, such as Claude Code or Codex, doing the work. Some keep working on one project; most take one task and stop.
  • Task One piece of work for an agent: usually an issue from your tracker, or something you typed.
  • Pull request Where every change lands, with its checks and, for screen changes, screenshots.
  • {{w.paneAlerts}} The short list of what only you can decide, each with the button that settles it.
  • {{w.briefMe}} Each morning, what merged, what opened and what waits for you.
  • Quiet Heavy jobs wait while you need your computer; {{w.quiet}} turns it on.
  • {{w.safetyTitle}} What stops an agent before a risky step: the guard, the sandbox and a daily cap.
